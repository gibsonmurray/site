# Gibson Murray

Dark-mode-only Next.js portfolio for Gibson Murray. The public site is a small
App Router app with external links for writing, book sales, and projects.

## Scripts

- `bun run dev` starts Next.js with Turbopack.
- `bun run build` creates the production Next build.
- `bun run start` serves the production build locally.
- `bun run lint` checks the active Next source and shadcn primitives.
